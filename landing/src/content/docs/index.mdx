Alera is a native workbench for CLI coding agents. You run Claude Code, Codex, Amp, Antigravity, OpenCode, Cursor, Copilot, Pi, Grok Build, fx, or any other terminal agent in a real PTY, each in its own Git worktree when the project is Git-backed.

It is not another AI IDE and it does not wrap a single chat backend. The desktop app is Flutter, and the runtime that owns your terminals is a Rust sidecar that keeps running when you close the window. There is no Electron and no bundled Chromium.

## First Session

<Steps>

1. [Install Alera](/docs/install) for your platform, then open the app.
2. Register a [project](/docs/projects): an existing local folder, or a Git clone from a URL. Its first workspace opens on the project folder.
3. Open a [terminal tab](/docs/terminals) and launch an [agent CLI](/docs/agents) the same way you would in any shell.
4. For the next task, save an [agent profile](/docs/agent-profiles) for your CLI and press `Mod+Shift+N` for [New Workspace](/docs/new-workspace) (`Mod` is ⌘ on macOS and Ctrl on Windows and Linux). Describe the task, pick the profile, and, in a Git project, choose **New Worktree** so the task gets [its own branch and folder](/docs/worktrees). AI Assist names the workspace, and the agent starts with your prompt.

</Steps>

That is the whole loop. Everything else in these docs is how to keep several of those loops running at once without collisions.

## What These Docs Cover

These pages are for people *using* Alera: install, the workbench, agents, review, coordination, remote hosts, and the companion app. They describe behavior that ships today.

Contributor internals (architecture, CI, design-system rules, release signing) stay in the [GitHub repository](https://github.com/leynier/alera), not here.

<Callout>
Alera is in public beta. The core workflow is shipping: projects, worktree workspaces, multi-agent terminals, persistent sessions, live agent states, visual source control, pull requests and checks, remote SSH hosts, the Android companion, and agent quota tracking.
</Callout>
