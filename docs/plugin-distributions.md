# Alera Plugin Distributions

Five separate archives are generated by the static website build and standalone Bun scripts. The ChatGPT plugin manifest is at version 1.1.0 (bumped when the bundled orchestration skills moved to contract v3); the Claude web, GrokBot Cursor, Agent Plugin and GitHub Copilot manifests stay at 1.0.0. Every archive bundles the same `edge/skills/` sources, so a skill change changes all five archives' bytes. The combined example is experimental, generated only through an explicit script, and has no website route or published CI artifact. Google and Gemini are excluded.

## Formats And Installation Boundaries

| Distribution | Manifest And MCP | Documented Installation | Limits |
| --- | --- | --- | --- |
| ChatGPT | Existing root and `.codex-plugin` manifests, remote MCP and OpenAI OAuth metadata | Codex/local desktop import; public web distribution requires approved portal publication | Any imported MCP declaration is desktop-only, including HTTPS; preservation does not establish directory publication or OAuth |
| Claude web | `.claude-plugin/plugin.json`, `.mcp.json` with `type: http` | Paid web account uploads ZIP or `.plugin`, then adds and connects the connector | Code validation is not web upload, OAuth, or token-refresh proof |
| GrokBot Cursor | `.cursor-plugin/plugin.json`, native `mcp.json` with fixed URL | Cursor local folder import, reload, Customize | Grok Bot only documents available-plugin connection; no arbitrary ZIP import or native Cursor synchronization is established |
| Agent Plugin | Root `plugin.json` and `mcp.json`, both official 1.0.0 schemas | Client-managed import of the extracted root | Pure: no provider extensions, client metadata, hooks, image fields, or installers; OAuth and installation are outside the standard |
| GitHub Copilot | Root Agent Plugins 1.0.0 documents and client-specific setup skill | CLI extracted-folder install, VS Code local-plugin registration, app marketplace browsing; CLI-configured skills/MCP are documented as available in the app | No documented Copilot logo or interface field; actual app inventory and OAuth remain separate checks |

Exact channel names `GrokBot Cursor` and `Agent Plugin` are website labels. Their manifest identifiers obey the documented lowercase naming requirements. Cursor's Alera logo is committed at the declared relative path. No image field is invented for the standard or Copilot. `com.github.copilot` is documented for optional client components, not arbitrary image metadata; these skills-and-MCP packages do not need it.

Sources verified on 2026-10-10: [Cursor formats](https://cursor.com/docs/reference/plugins), [Cursor local import](https://cursor.com/docs/plugins#test-plugins-locally), [Grok Bot connections](https://cursor.com/help/grok-bot/connect-plugins), [Agent Plugins specification](https://agent-plugins.org/specification), [Agent Skills](https://agentskills.io/specification), [Copilot plugins](https://docs.github.com/en/copilot/concepts/agents/about-plugins), [Copilot reference](https://docs.github.com/en/copilot/reference/copilot-cli-reference/cli-plugin-reference), and [VS Code plugins](https://code.visualstudio.com/docs/agent-customization/agent-plugins). The standard's [compatible-client catalog](https://agent-plugins.org/compatible-clients) lists Grok Bot and Kiro, but does not establish native Cursor ZIP import or a universal install procedure. No Kiro-specific implementation is added.

## Reproduction And Checksums

From `landing/`, run `bun install --frozen-lockfile`, then `bun run package:plugin`, `bun run package:claude-plugin`, `bun run package:cursor-plugin`, `bun run package:agent-plugin`, or `bun run package:copilot-plugin`. `bun run build` generates all production archives under `landing/dist/downloads/`. Each ZIP has a `.sha256` sibling; verify from the archive's containing directory with `sha256sum -c <archive>.sha256`. Claude's `.plugin` alias contains identical ZIP bytes.

## Combined Experiment

Run `bun run package:experimental-plugin` explicitly to generate `build/experimental-plugin/alera-combined-experimental.zip` and checksum. It has one shared set of five portable skills and references, root Agent Plugins/Copilot documents, `.codex-plugin`, `.claude-plugin`, and `.cursor-plugin` manifests, and shared Alera images. Its core manifest uses a standard `com.openai` extension, so the experiment is not the pure fourth distribution. Native `.mcp.json` uses Claude HTTP configuration without the separate production OpenAI OAuth declaration. Configuration differences remain deliberate experimental limits.

The reviewed first example is 92167 bytes, SHA-256 `ae85bbba854633a46425efa9dc25fe8e89792af786500eb21584fb72e335e17a`. It was generated locally and delivered privately once as explicitly requested; it is not a public download or CI artifact.

| Client | Evidence | Remaining Boundary |
| --- | --- | --- |
| Agent Plugins core | Root manifest and MCP pass official 1.0.0 schemas; one immediate set of five skills | Client runtime support, install, and authorization remain untested |
| Copilot CLI | In a temporary probe with distinct manifest names, `plugin list` selects `alera-root-probe`, proving root precedence while other manifest files coexist | Listing does not prove component execution or OAuth; app and VS Code were not installed |
| Claude Code | Validator selects `.claude-plugin/plugin.json` despite competing files and passes strict validation | This validates a native manifest, not every web upload rule or extra-file acceptance |
| Claude web | User reports preliminary import/use success for one of three agents' experimental ZIPs, not yet identified; [upload rules](https://platform.claude.com/docs/en/manage-claude/plugins-api#upload-requirements) describe native-manifest constraints | Do not infer that all multi-manifest ZIPs fail; this artifact, OAuth, and runtime coverage remain unverified |
| ChatGPT/Codex | Actual sent ZIP and separate OpenAI archive both declare remote MCP; official import policy marks these desktop-only | This is independent of stdio or competing manifests; public web requires reviewed publication, not a speculative ZIP edit |
| Cursor/Grok Bot | Both Cursor formats and available-plugin connections are documented separately | Co-location priority and Grok Bot arbitrary ZIP import are not established |

No validator result is described as universal compatibility, a real web installation, OAuth, refresh, or runtime connectivity. The experiment does not add Google/Gemini, Kiro implementation, local executables, hooks, or secrets.
